> ⚠️ **투자 자문 아님**: 본 프로그램이 생성하는 모든 정보(스코어, 국면 추정, 알림, 리포트)는
> **투자 참고용으로만 제공되며, 투자 자문이나 매매 추천이 아닙니다.** 투자 판단과 그에 따른
> 책임은 전적으로 이용자 본인에게 있습니다. 모든 산출값은 "~신호가 관측됨", "~국면일
> 가능성(스코어 XX)"과 같은 확률적 표현이며, 단정적 판단이 아닙니다. 스코어링 로직은
> 확률적 추정이며 실제 세력 개입 여부를 보장하지 않습니다(오탐 가능).

## 프로젝트 개요

국내(코스피/코스닥) 상장 종목의 시세·수급·신용잔고·공매도·공시 등 공개 시장 데이터를
정량 지표로 변환해, 매집(Accumulation) → 상승(Markup) → 분산(Distribution) → 하락(Markdown)
중 어느 국면에 있을 가능성이 높은지 점수화하여 참고 정보로 제공한다.

전체 목표·범위·지표 정의·법적 가드레일·아키텍처·백테스트 방법론 등은
[프로젝트 지침서](docs/project_spec.md) 및 하위 문서(`docs/`)를 최상위 기준으로 삼는다.

## 범위 밖 (하지 않는 것)

- **자동 주문 실행 없음**: 증권사 API는 시세·계좌 조회 목적으로만 사용하며, 스코어를
  근거로 매수/매도 주문을 자동 전송하는 코드를 만들지 않는다.
- **유료 신호 판매/리딩방 운영 없음**: 비영리·개인 사용 한정.
- **세력의 신원 특정 없음**: 오직 공개된 가격·거래량·수급 패턴만 다룬다.
- **초단타 HFT 아님**: 분~일 단위 스윙성 관찰이 목표.

자세한 원칙은 [`docs/legal_notice.md`](docs/legal_notice.md) 참고.

## 폴더 구조

```
config/     설정 파일 (API 키는 여기 두지 않고 환경변수 참조만)
data/       원시/정제/캐시/백테스트 데이터 (git 미포함)
scripts/
  collectors/  데이터 수집 모듈 (소스별 분리)
  indicators/  지표 계산 모듈 (카테고리별 분리)
  scoring/     세력 개입 의심 지수 + 국면 분류
  backtest/    백테스트 실행/지표
  dashboard/   Streamlit 대시보드
  alerts/      텔레그램 알림 (정보 통지, 주문 아님)
  utils/       로거, 설정 로더
docs/       아키텍처, 지표 명세, 데이터 소스 명세, 법적 고지
tests/      단위/통합 테스트
project_작업일지.md   작업 기록 (모든 세션은 이 파일부터 확인)
sources.md            리서치 출처 및 신뢰도
```

## 시작하기

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # 실제 키 값 입력 (커밋 금지)
```

## 보안

API 키·계좌정보는 코드에 하드코딩하지 않고 `.env` + 환경변수로만 관리한다
(`config/settings.yaml`은 `${ENV_VAR}` 형태로 참조만 함). 자세한 내용은
[`docs/legal_notice.md`](docs/legal_notice.md)와 지침서 9장 참고.

## 개발 진행 방식

- 모든 파일 생성/수정은 [`project_작업일지.md`](project_작업일지.md)에 기록한다.
- 파일 하나가 18KB를 넘지 않도록 설계 단계에서 모듈을 분할한다.
- 새 세션은 반드시 작업일지의 최신 항목부터 확인하고 이어서 작업한다.
