# 법적/윤리적 고지사항 및 가드레일

> 출처: 지침서(`docs/project_spec.md`) 2장. 이 문서는 프로젝트 전체에서 예외 없이 지켜야
> 하는 최상위 규칙을 요약하고, UI/알림/리포트에 삽입할 표준 문구를 제공한다.

## 최상위 원칙 (요약)

1. **투자자문 아님 고지** — 모든 리포트/대시보드/알림에 표준 고지 문구 표시.
2. **자동매매 주문 실행 금지** — 스코어/신호를 근거로 증권사 API에 매수·매도 주문을
   자동 전송하는 코드를 만들지 않는다. 알림 = 정보 통지까지만.
3. **비영리·개인 사용 한정** — 산출물을 불특정 다수에게 유료로 제공(리딩방 등)하지 않는다.
4. **시세조종 목적 무관 고지** — 시세 관찰·분석 도구이며, 자본시장법 제176조 시세조종행위와
   무관하다. 허위 매수·매도(가장매매, 통정매매) 등에 사용 금지.
5. **확정적 판단 표현 금지** — "세력주다", "지금 사라/팔아라" 같은 단정적 문구 출력 금지.
   항상 "~신호가 관측됨", "~국면일 가능성(스코어 XX)" 형태의 확률적 표현만 사용.
6. **데이터 이용약관 준수** — 각 데이터 소스의 ToS·요청 빈도 제한 준수. 과도한 크롤링 금지.
7. **오탐 가능성 명시** — 스코어링은 확률적 추정이며 실제 세력 개입 여부를 보장하지 않음.
8. **애매한 상황** — 기능을 임의로 확장하지 말고 `project_작업일지.md`에 이슈로 기록 후
   사용자 확인 요청.

## 표준 고지 문구 (README / 대시보드 / 알림 공통)

```
본 정보는 투자 참고용으로만 제공되며, 투자 자문이나 매매 추천이 아닙니다.
투자 판단과 그에 따른 책임은 전적으로 이용자 본인에게 있습니다.
본 스코어링은 과거 데이터 패턴에 기반한 확률적 추정이며, 실제 세력 개입 여부를
보장하지 않습니다(오탐 가능).
```

- 대시보드: 페이지 하단에 고정 표시.
- 텔레그램 알림: 매 메시지 말미에 짧은 버전 첨부
  (`⚠️ 투자 참고용 정보이며 투자 자문이 아닙니다.`).
- 리포트(마크다운/PDF): 상단 요약 직후 1회, 하단에 전체 문구 1회.

## 범위 밖 — 절대 구현하지 않는 기능

- 증권사 API를 통한 자동 매수/매도 주문 전송 함수
- 제3자 대상 유료 신호 판매, 리딩방/오픈채팅방 자동 배포
- 계좌·개인 신원과 연계해 "세력의 정체"를 특정하는 기능
- 허위 매수·매도 반복(가장매매/통정매매)을 유발하거나 돕는 기능

## 보안 (9장 요약, 상세는 README "보안" 섹션 및 `.env.example` 참고)

- API 키·계좌정보·토큰은 코드에 하드코딩하지 않고 `.env`로만 관리.
- 로그(`logs/`)에 민감정보가 그대로 출력되지 않도록 마스킹.
- 증권사 API의 주문 스코프는 신청하지 않거나, 신청해도 호출하지 않는다.
