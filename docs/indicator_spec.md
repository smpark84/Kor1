# 지표 명세

> 출처: 지침서(`docs/project_spec.md`) 1.4~1.5장. 각 지표는 단독 신뢰도가 낮으므로
> **반드시 여러 지표를 조합**해서 사용한다. 임계값(예: 거래량 300%, 체결강도 150%)은
> 초기 참고값일 뿐이며 6장 백테스트로 재검증 후 확정한다.

## 국면(Phase) 정의 — Wyckoff 4국면 프레임 참고

| 국면 | 특징 조합 (예시, 백테스트로 임계값 튜닝) |
|---|---|
| 매집(Accumulation) | 장기 횡보 + 거래량 서서히 증가 + 기관/외국인 순매수 전환 + 저점 완만한 상승 + 신용잔고 안정 |
| 상승(Markup) | 거래량 폭발적 증가 + 동적 VI 발동 빈발 + 체결강도 150%↑ 지속 + 정배열 전환 |
| 분산(Distribution) | 고점권 거래량 유지되나 상승폭 둔화 + 체결강도 100% 하회 전환 + 기관/외국인 순매도 전환 + 개인 순매수 급증 |
| 하락(Markdown) | 거래량 감소 속 하락 지속 + 신용잔고 급감(반대매매 추정) + 공매도 잔고 증가 |

## 스코어링 설계안 (1차 제안, 6장 백테스트로 검증 후 확정)

1. 각 지표를 정규화(z-score 또는 백분위 랭크).
2. 가중합으로 "세력 개입 의심 지수(0~100)" 산출.
3. 지표 조합 패턴을 규칙기반(rule-based) 또는 간단한 분류 모델(로지스틱회귀,
   그래디언트부스팅 등)로 국면 라벨에 매핑.
4. 가중치·임계값은 반드시 백테스트(out-of-sample 검증 포함)로 확정 — 과거 데이터에
   과최적화하지 않도록 파라미터 수를 최소화한다.

## MVP 우선 지표 (2026-07-10 사용자 확정)

Phase 1(EOD 배치)에서 실시간 데이터 없이 안정적으로 계산 가능한 지표 5개로 확정했다
(작업일지 참고). `scripts/indicators/`에 아래 순서대로 구현한다:

1. 거래량 급증률 (A) — pykrx OHLCV로 즉시 계산 가능
2. 기관+외국인 동반 순매수 연속일수/누적대금 (B) — pykrx 투자자별 매매동향
3. 신용융자잔고율 증가 추이 (C) — pykrx/FreeSIS
4. 정배열 전환 + 눌림목 패턴 (F) — OHLCV 파생, 별도 소스 불필요
5. VI 발동 이력 (E) — KRX 데이터 (일별 집계로 근사 가능한지 확인 필요)

체결강도/호가잔량(D)은 실시간 데이터가 필요해 Phase 2 이후로 분류.
